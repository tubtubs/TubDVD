# TubDVD
Bouncing DVD logo in 1.12.1. Triggers when afk, or with `/dvd toggle`. See `/dvd` for more commands.
Sounds stolen from the [TWowenWilson](https://github.com/CosminPOP/TWOwenWilson) addon

# Installation:
1. Click the Code button to the upper right hand corner and select download or click [here](https://github.com/tubtubs/TubDVD/archive/refs/heads/master.zip).
2. Unzip the download into your Interface/Addons folder in your WoW directory. Eg: *C:\Games\WoW\Interface\Addons*
3. Rename the folder from *TubDVD-master* to *TubDVD*
4. Restart WoW and enable the addon from the character selection screen. Ensure your addon memory cap is set to 0 (no limit) or a high number like 256.

You can also use the [GitAddonsManager](https://gitlab.com/woblight/GitAddonsManager) to install this addon.

* If there are any further issues with installation, ensure that *TubDVD.toc* is in the root folder. There should be no subdirectories. Eg: *C:\Games\WoW\Interface\Addons\TubDVD\TubDVD.toc*

# Known Issues
* Sometimes when the animation starts it'll be out of bounds, and may spam the Owen Wilson wow sound effect (false corner hit). I haven't found a good way to prevent it, but seems to happen more often with higher speed values.
